About Ajax Proxy

Ajax Proxy is a browser extension for inspecting, mocking, modifying, and redirecting web requests according to rules configured by the user.

Information the extension handles

When the extension is enabled, it processes request URLs and methods and, when needed to apply or diagnose a rule, request and response headers, status codes, and text bodies. These may contain web browsing activity or website content, and may include sensitive information supplied by the website or the user. The extension processes this information in the browser to match rules, apply the user-selected action, and show request outcomes. Diagnostic capture is user-initiated and is shown in the open panel for that session.

The extension stores user-created rules and settings, including match patterns, configured mock or redirect responses, optional rule code, tags, preferences, and hit counters, in the browser's local extension storage. The theme and language preferences may also be stored in the browser's local storage. This information remains on the user's device unless the user explicitly exports it or otherwise shares it.

How information is used and shared

Ajax Proxy does not send request or response data, rules, settings, or usage analytics to the developer or to an Ajax Proxy-operated server. It does not sell this information or use it for advertising. The extension may pass information to the destination selected by the website or by a redirect rule so that the browser can perform the requested operation. Those destinations are controlled by the website or by the user's own rule configuration, not by Ajax Proxy.

The extension does not include remotely hosted executable code. User-provided rule functions run locally in the browser's isolated sandbox.

User control and deletion

The extension only applies configured behavior while its global switch is enabled. Users can disable it, remove rules and diagnostic records through the extension interface, or remove the extension. Removing the extension through the browser may also remove its locally stored extension data. Users can export their rules using the extension's backup feature; exported files are under the user's control.

Contact

For questions or privacy requests, open an issue at github.com/Nyakooo/ajax-proxy/issues.

Ajax Proxy 隐私权政策

最后更新：2026 年 9 月 29 日

Ajax Proxy 是一款浏览器扩展，用于按照用户配置的规则检查、模拟、修改和重定向网页请求。

扩展会处理的信息

扩展启用时，会在浏览器本地处理请求 URL、请求方法；为了匹配规则或诊断问题，也可能处理请求与响应标头、状态码及文本正文。这些信息可能包含浏览记录或网站内容，也可能包含网站或用户提供的敏感信息。扩展在浏览器中处理这些信息，以匹配规则、执行用户选择的操作并显示请求结果。诊断捕获由用户主动开启，记录仅在当次打开的面板会话中显示。

用户创建的规则和设置会保存在浏览器的扩展本地存储中，包括匹配条件、配置的模拟或重定向响应、可选规则代码、标签、偏好设置和命中计数。主题和语言偏好也可能保存在浏览器本地存储中。除非用户主动导出或以其他方式分享，否则这些信息保留在用户设备上。

信息的用途与共享

Ajax Proxy 不会将请求或响应数据、规则、设置或使用分析数据发送给开发者或 Ajax Proxy 运营的服务器；不会出售这些信息，也不会将其用于广告。浏览器可能会将信息发送到网站指定的目标地址，或用户在重定向规则中配置的目标地址，以完成相应请求。这些目标由网站或用户自己的规则配置决定，而非由 Ajax Proxy 指定。

扩展不包含远程托管的可执行代码。用户编写的规则函数在浏览器的隔离沙箱中本地运行。

用户控制与删除

扩展仅在全局开关开启时应用已配置的行为。用户可以关闭扩展、通过扩展界面删除规则和诊断记录，或移除扩展。通过浏览器移除扩展也可能一并删除扩展本地存储的数据。用户可以使用备份功能导出规则；导出文件由用户自行控制。

联系方式

如有隐私相关问题或请求，请通过 GitHub Issues联系项目维护者。
