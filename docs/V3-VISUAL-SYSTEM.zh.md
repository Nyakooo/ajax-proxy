# Ajax Proxy V3 界面视觉基线

状态：阶段 4 的品牌到界面视觉基线，供 Vue 3 / PrimeVue 原型及后续组件迁移使用。它统一设计语言和基础 token，不代表规则编辑器、完整组件状态或全套界面已完成验收。

## 视觉原则

- 以品牌深青色承担主要操作和结构，薄荷绿、珊瑚色、琥珀色分别表达请求活动、响应 / 命中和代理节点；状态文案与图标同时提供含义，不只靠颜色区分。
- 浅色和深色模式共享相同的语义层级；组件读取语义 token，不直接复制品牌颜色。
- 排版与间距优先密度适中、可扫描；请求路径、代码和计数使用系统等宽字体，不下载大型字体资源。
- 关键控件保留清楚的边界、选中状态和键盘焦点；减少动态效果时尊重系统偏好。

## 颜色与语义 token

| 角色                                    | 浅色      | 深色      | 用途                                |
| --------------------------------------- | --------- | --------- | ----------------------------------- |
| 页面背景 `--ap-page`                    | `#F5F9F8` | `#102A30` | 应用外层背景                        |
| 提升表面 `--ap-raised`                  | `#FFFFFF` | `#16353B` | 面板、卡片和控件表面                |
| 主要文字 `--ap-text-primary`            | `#12343B` | `#EAF2F1` | 标题与主要内容                      |
| 次要文字 `--ap-text-secondary`          | `#53686B` | `#B4C6C7` | 正文说明、操作元信息                |
| 三级文字 `--ap-text-tertiary`           | `#5F7376` | `#91A8AA` | 小字号辅助信息；仍须保证可读        |
| 主操作 `--ap-brand-teal`                | `#006D75` | `#006D75` | 主按钮、链接和活动路径              |
| 主操作文字 `--ap-text-on-primary`       | `#F5F9F8` | `#F5F9F8` | 主操作前景                          |
| 键盘焦点 `--ap-focus`                   | `#006D75` | `#20AA9A` | 3 px 可见焦点轮廓                   |
| 结构边界 `--ap-border`                  | `#DCE8E6` | `#2B4A50` | 输入、分隔线和面板边界              |
| 正常状态 `--ap-status-positive`         | `#006D75` | `#8CE0D5` | 必须与“启用 / 成功”等文字或图标并用 |
| 危险状态文字 `--ap-status-danger-text`  | `#B54740` | `#FF968D` | 错误文字；品牌珊瑚色本身仅用于点缀  |
| 警告状态文字 `--ap-status-warning-text` | `#684A16` | `#F6BD58` | 警告文字；配合警告图标与文案        |

品牌 primitive 保留于 `--ap-brand-ink`、`--ap-brand-teal`、`--ap-brand-mint`、`--ap-brand-coral` 和 `--ap-brand-amber`。`--ap-ink`、`--ap-teal` 等旧原型变量是兼容别名；新组件优先使用语义 token。薄荷绿、珊瑚色和琥珀色在浅色背景上对比不足以承载普通字号文字，不能独立表达错误、成功或警告。

按 WCAG 2.2 的文字对比指导，普通文字目标至少 4.5:1，大号文字至少 3:1；识别控件或状态所需的非文本视觉信息目标至少 3:1。以上 sRGB 比值由 token 前景 / 背景色计算，用于原型基线，不代表完整无障碍审计。示例：浅色次要文字 / 页面背景 5.56:1、三级文字 / 页面背景 4.71:1、深色三级文字 / 卡片背景 5.22:1、主操作文字 / 主按钮 5.75:1。参考 [W3C WCAG 2.2 对比度最低要求](https://www.w3.org/TR/wcag/#contrast-minimum) 和 [非文本对比](https://www.w3.org/WAI/WCAG22/understanding/non-text-contrast.html)。

## 字体、尺寸和图标

- 界面字体：`Inter, SF Pro Text, Segoe UI, system-ui, sans-serif`；不捆绑外部字体。CSS token 为 `--ap-font-ui`。
- 代码字体：`SFMono-Regular, Consolas, ui-monospace, monospace`；CSS token 为 `--ap-font-code`。同类数据使用同一字体栈，不混用不同 mono 字体。
- 字号基线：12 / 14 / 16 / 24 px；极密集计数可使用 10–11 px，但要以实测对比度和缩放后可读性验收，避免作为解释性正文。
- 间距基数为 4 px，常用刻度 4 / 8 / 12 / 16 / 24 / 32 px；token 为 `--ap-space-1` 至 `--ap-space-8`。面板和控件圆角常用 4 / 8 / 12 px；标准控件高度 36 px，后续组件按实际扩展面板高度在 32 / 36 / 40 px 中选用。
- 产品功能图标采用仓库可维护 SVG，统一 16 / 20 / 24 px 光学尺寸和 1.75–2 px 线宽；图标按钮需有可访问名称。不要将依赖系统字形的 Unicode 符号作为最终导航图标。
- 关键文字、代码、控件边界与焦点在浅 / 深主题分别验收；焦点环不得被裁切。动态效果在 `prefers-reduced-motion: reduce` 下收敛。

## 当前实现和待验收边界

原型 CSS 已引入语义颜色、字体、间距、圆角、控件高度和主题焦点 token；次要文字 token 同步提升到可读对比度。此提交只校准共享基线，不重做整个原型布局。原型当前仍有紧凑字号、独立间距和 Unicode 示例图标；它们不构成最终规范的例外批准。规则行操作、完整表单与错误 / 加载 / 禁用状态、屏幕阅读器路径、真实扩展弹窗宽度和 200% 缩放需在相应 UI 实现阶段继续验收。

品牌概念、SVG mark 与扩展图标场景见 [`V3-BRAND-DIRECTION.zh.md`](V3-BRAND-DIRECTION.zh.md)；关键页面结构和流程见 [`V3-PANEL-IA.zh.md`](V3-PANEL-IA.zh.md)；当前 PrimeVue styled / Pass Through / unstyled 原型验证见 [`V3-UI-PROTOTYPE.zh.md`](V3-UI-PROTOTYPE.zh.md)。
