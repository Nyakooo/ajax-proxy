适用于 Chrome Web Store 和 Microsoft Edge Add-ons 的简体中文条目。商店版本尚未审核通过前，描述、README 和发布说明都不得写成已上架。

## 标题

Ajax Proxy

## 简短说明

在浏览器中 Mock 接口响应、重定向请求，快速验证前端边界场景。

## 详细说明

Ajax Proxy 是面向 Web 开发者的本地浏览器工具。接口尚未开发完成时，它可以直接为匹配请求返回预设 JSON；也可以将请求重定向到另一个地址，帮助你在不修改业务代码的情况下联调和验证页面。

**主要功能**

- **Mock 尚不存在的 API：** 按 URL 和请求方法匹配请求，由扩展直接返回 JSON 响应与状态码。Mock 模式跳过网络请求，不需要后端真的提供该接口。
- **替换真实响应：** 对匹配请求先发送真实网络请求，再用配置的 JSON 内容替换响应。
- **重定向请求：** 支持静态目标地址、静态请求头、排除 URL，以及只用于 Fetch 的函数目标地址。
- **管理规则：** 搜索、筛选、排序、置顶、标签分组和批量启停；多条规则同时命中时，按列表顺序使用首条启用规则。
- **临时诊断：** 查看请求命中、Mock、替换、重定向或回退状态。
- **JSON 与函数编辑：** 使用结构化 JSON 编辑器；受限函数可生成 Fetch 响应或重定向目标。
- **备份与恢复：** 将 V3 规则导出为独立 JSON 文件，再在另一份 V3 安装中恢复。

扩展在浏览器本地处理规则，不提供托管代理或账号服务。仅在信任的页面上启用规则；分享日志或备份前，请移除请求数据、Cookie、令牌和私有函数代码。

**请求类型支持**

- 静态 Mock 和普通静态 JSON 响应替换支持 Fetch 与支持的异步 XHR。
- 函数响应和函数重定向仅支持 Fetch；XHR 保留原始响应或原始 URL。

**兼容性与升级**

- 支持 Chrome 141+ 与 Microsoft Edge 140+ 稳定版。
- V2 与 V3 规则和备份格式不兼容，且没有自动迁移。升级前请导出并另存 V2 备份，再在 V3 中按需重新创建规则。
- 请勿将 V2 备份导入 V3。V3 首次使用后建议立即导出一份 V3 备份。
